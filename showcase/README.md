# Optional portfolio viewer

The repository includes the page implementation and lightweight static imagery. The complete portable viewer, including all four full Gaussian stages and video media, is distributed as `gaussian-project-showcase.zip` in [Releases](https://github.com/Xuyw041006-arch/semantic-incremental-gaussians/releases).

Extract that archive and run its included server:

```bash
python3 serve.py
```

Follow the URL printed by the server. The portfolio is optional; the project introduction is available directly in the repository's Chinese and English README files.

The viewer replays a previously trained model. It does not run Gaussian optimization in the browser.
