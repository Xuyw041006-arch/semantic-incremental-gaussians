# 平衡语义控制器：迭代实验

第一版的 32 组完整因子消融中，B 的平均 PSNR 效应在两个场景均偏负，完整模型在 TUM 略有退步。因此保留第一版全部原始指标，另建此版本，不覆盖旧实验。

本版改变三处：S 使用有下限的均匀/难度混合采样，降低语义区域裁剪比例；B 限制语义稀缺度对点准入、增密和置换的权重；R 增加回放池的时间覆盖，并随着数据前缀扩展逐步提高旧帧比例。几何损失、步数、分辨率、点数上限保持相同。

筛查使用原两个场景 seed 7，规则在 `iteration-plan.json` 中记录。第二个种子用于确认；TUM desk2 是未用于调参的另一段录像，但与 desk 处于同一办公室。不能据此宣称跨环境泛化或显著性。全部实验均使用已知位姿；厨房依赖离线 COLMAP，不能称为严格在线 SLAM。区域分数以 SAM 候选区域为参考，不能称为人工语义/部件真值准确率。

`run_iteration.py` 支持 screen、factorial、confirmation、verification 四个阶段。每组独立进程；已完成组通过 run.json 跳过，未完成组从头重跑。所有候选和失败日志必须保留。

主消融之外，另补 4 组匹配回放概率、时间覆盖、位置新颖性与容量的对照，只清空 R 的语义覆盖信息。这是事后诊断，用于区分语义选帧和更多回放的贡献，不用于重新筛选候选模型。L4 共 32 组主消融、4 组独立录像验证、4 组回放对照。
